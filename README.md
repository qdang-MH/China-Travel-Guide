# China — The Four Seasons Collection (Version 3.2)

This is a modular traveler-focused website.

## Included
- Polished homepage
- Complete Trip 1 overview
- Fourteen detailed daily itinerary sections
- Sticky day navigation
- Destination guides for Shanghai, Huangshan, Zhangjiajie, Fenghuang, and Chengdu
- Mobile-friendly CSS
- Trip dashboard
- Clickable route map
- Compact daily summary panels

## Local Preview
Open `index.html`.

## GitHub Pages
Upload the contents of this folder to the root of your GitHub repository, then enable:
Settings → Pages → Deploy from a branch → main → /(root)

## Notes
Hotel prices are planning estimates, not live quotes.
Exact train numbers, flight details, restaurant reservations, and Chinese-language addresses should be added after bookings are finalized.
